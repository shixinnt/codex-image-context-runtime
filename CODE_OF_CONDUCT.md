# Community Code of Conduct

This project aims to be a practical, welcoming place for people improving image-heavy Codex workflows.

## Expected behavior

- Be respectful, specific, and patient.
- Critique ideas and code rather than people.
- Share the smallest safe reproduction and distinguish observation from inference.
- Respect privacy, copyright, service rules, and the cost of remote provider calls.
- Disclose when you maintain, promote, or financially benefit from a related project.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing another person's private information or credentials.
- Spam, deceptive claims, fabricated benchmarks, or repeated unsolicited promotion.
- Encouraging users to bypass provider safety, platform policy, or authorization boundaries.

## Moderation

Maintainers may edit, hide, lock, or remove contributions that violate these expectations and may restrict repeated abuse. For ordinary community concerns, use the repository's GitHub moderation and reporting controls. For a sensitive security concern, use the private vulnerability-reporting flow in [SECURITY.md](SECURITY.md).

Enforcement decisions should be proportionate, documented when practical, and focused on protecting contributors and the project's technical integrity.
