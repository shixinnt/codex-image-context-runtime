# Support

## Start here

1. Read the [installation and configuration guide](README.md#install-and-configure).
2. Run `npm run doctor` from a clone of the repository.
3. Check [Troubleshooting](docs/troubleshooting.md).
4. Search existing GitHub issues and discussions before opening a new thread.

## Where to ask

- **Installation or reproducible defect:** open a GitHub issue using the appropriate template.
- **Usage question, workflow idea, or field report:** use GitHub Discussions.
- **Security boundary concern:** use the private **Report a vulnerability** flow described in [SECURITY.md](SECURITY.md).

## Helpful, privacy-safe details

Include the tagged release, operating system, Node.js version, Codex surface and version, provider mode, the exact bounded error code, and the smallest synthetic reproduction. The output of `npm run doctor -- --json` is designed to be reviewable, but inspect it before posting.

Do not post credentials, personal information, private images, prompts, provider responses, absolute paths, or an entire Runtime directory. Replace project names and workspace identifiers when they reveal sensitive information.

## Support boundary

This project is maintained by its open-source contributors on a best-effort basis. It does not provide official OpenAI support and cannot repair an already-corrupted native Codex task, provider outage, network failure, or service-side rate limit.
